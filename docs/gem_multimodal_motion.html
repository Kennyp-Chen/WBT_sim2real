GEM 多模态动作前端

GEM/GENMO 是人体动作估计和生成模型，不是机器人低层控制策略。它必须通过 SMPL 到机器人动作的适配层接入 SONIC 或 BFM-Zero。

完整技术报告请打开同目录的 gem_multimodal_motion.md；长期实施顺序和进度请查看 tutorials/gem-integration-plan.md。

推荐架构

视频 / 文本 / 音频 / 音乐
    -> GEM
    -> SMPL body parameters
    -> 机器人重定向 / IK
    -> SONIC 或 PiPlus BFM-Zero
    -> sim2sim / 真机

可行性

输入判断第一步
录制视频可行，最适合第一里程碑GEM smpl_params.pt 到 SONIC SMPL ZMQ
实时视频可行，但有 120 帧 context 和 GPU 延迟先测 ONNX full / --no_imgfeat
语言可行，当前更接近 10 秒分段生成增加 prompt queue 和片段拼接
音乐/音频模型支持，实时输入需要自建前端先复现离线音频条件样本

当前结论

最短路径是 GEM 视频到 SONIC SMPL sim2sim。PiPlus BFM-Zero 需要额外的 SMPL-to-PiPlus 22DoF 重定向器，不能直接接收 GEM 输出。

官方项目：NVlabs/GENMO；论文：arXiv 2505.01425。
